# Капибара: приключение

Двухмерная бродилка с видом сбоку: капибара ходит, бегает, прыгает и собирает
монетки. Отдельный проект — соседняя игра (Star Conquest) не затронута.

Стек тот же: **Phaser 3.90 + Vite**, чистый JavaScript, вся графика рисуется
кодом (в сборке нет ни одной картинки и ни одного звукового файла).

## Как запустить

```bash
npm install --prefix capybara
```

```bash
npm run dev --prefix capybara
```

Откроется на http://localhost:5174. Сборка для портала:

```bash
npm run build --prefix capybara
```

Готовая игра ложится в `capybara/dist/` (сейчас ~1,2 МБ, 332 КБ в gzip).
`index.html` лежит в корне архива, в именах файлов нет пробелов и кириллицы —
как требует Яндекс.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Идти | ← → или A/D | кнопки ◀ ▶ слева |
| Прыжок | Пробел, ↑ или W | кнопка ▲ справа |
| Ускорение | Shift | кнопка » (появляется после покупки) |
| Пауза | Esc | кнопка ❚❚ вверху справа |

Буквы читаются по физической клавише, поэтому раскладка не важна — требование
модерации. Кнопки на экране появляются только на сенсорных устройствах.

## Правила игры

**Звёзды за уровень** считаются по доле собранных **монеток**:

| Собрано монет | Итог |
|---|---|
| 100% | ⭐⭐⭐ |
| 70% и больше | ⭐⭐ |
| 50% и больше | ⭐ |
| меньше 50% | уровень не пройден, 0 звёзд |

Следующий уровень открывается, когда предыдущий пройден хотя бы на одну звезду.

**Вкусняшки** (круассан, кекс, мороженое) появляются на уровне случайно: в
карте есть помеченные места, и в каждом вкусняшка возникает с вероятностью 55%
(`TREAT_CHANCE` в `src/config.js`). Каждая даёт +5 монет в кошелёк, но **в
проценте для звёзд не участвует** — рейтинг зависит только от монеток.

Собранные монетки попадают в общий кошелёк в любом случае, даже если уровень
не пройден: они собраны честно.

**Магазин** (`src/shop.js`):

| Улучшение | Цена | Что делает |
|---|---|---|
| Двойной прыжок | 42 | второй прыжок в воздухе, перезарядка 6 сек |
| Ускорение | 65 | двойная скорость на 2 сек, перезарядка 6 сек |

Цена двойного прыжка равна числу монеток на первом уровне (42) — то есть за
первое улучшение нужно пройти уровень 1 на 100%. Цена считается прямо из
карты уровня: добавите монеток в `levels.js` — цена подстроится сама.

Перезарядка отсчитывается **от момента использования**. У ускорения это значит:
2 секунды работает, ещё 4 секунды ждём, и можно снова.

## Уровни

Уровни лежат в `src/levels.js` и собираются из кусочков-картинок в символах.
Кусочек — 12 столбцов на 12 рядов (ряд = 60 px, всего 720 — высота экрана):

```
#  земля              =  платформа (парящая)
o  монетка            *  место, где может появиться вкусняшка
^  шипы               m  ходячий монстрик
b  летающий монстрик  P  старт капибары       F  финишный флаг
```

Уровень — просто список кусочков подряд. Чтобы удлинить уровень или поменять
сложность, достаточно переставить названия в `LEVELS`.

Сейчас три уровня по нарастающей:

| Уровень | Длина | Монет | Что нового |
|---|---|---|---|
| 1. Солнечный луг | 156 клеток | 42 | пропасти, платформы, один монстрик |
| 2. Закатный берег | 204 клетки | 44 | шипы, пчёлы, монстрики у обрывов |
| 3. Вечерний лес | 204 клетки | 48 | всё вместе и почти без передышек |

Замеры на боте, который бежит вперёд и прыгает через препятствия, не собирая
монеты: 37 / 54 / 59 секунд. Живой игрок собирает монетки, лазает по
платформам и иногда падает — выходит примерно 1–2 минуты на уровень, как и
задумано.

**Правило проектирования уровней:** капибара прыгает на 183 px вверх (3 клетки)
и перелетает 3 клетки по горизонтали (числа проверены замерами в игре).
Поэтому пропасти шире 3 клеток бывают только с платформой посередине, а
платформы ставятся не выше 2 клеток над опорой. **Любой уровень проходится без
покупок из магазина** — улучшения ускоряют игру, но не открывают путь.

Проверить карты после правки:

```bash
node -e "import('./capybara/src/levels.js').then(m=>m.LEVELS.forEach((l,i)=>console.log(l.name, m.buildLevelMap(i)[0].length, m.countCoins(i))))"
```

Если у кусочка съедет ширина, `buildLevelMap` скажет об этом словами — с
именем кусочка и номером ряда.

## Что сделано под Яндекс Игры

Требования взяты из `../docs/yandex-games.md` (конспект от 2026-09-01).

- **Слой-адаптер площадки** (`src/platform/`). Игра не зовёт SDK напрямую:
  есть `yandex.js` и `local.js` с одинаковым набором методов. Локально (на
  `localhost`) всегда берётся местный адаптер, иначе SDK шлёт сообщения
  несуществующему порталу и засоряет консоль.
- **Game Ready** — `LoadingAPI.ready()` вызывается, когда текстуры готовы и
  заставка убрана. Неработающий Game Ready — частая причина отказа.
- Скрипт SDK подключён в `index.html` обычным тегом — так его точно увидит
  модерация. Побочный эффект: **локально в консоли будут ошибки**
  «No parent to post message» — это сам SDK ищет портал и не находит.
  На игру они не влияют, наш код в это время работает через `local.js`.
- **Разметка геймплея** — `GameplayAPI.start()/stop()` на старте уровня,
  паузе, меню и конце уровня.
- **Пауза от площадки** — `game_api_pause` останавливает игру и звук.
- **Автоопределение языка** — `environment.i18n.lang`; русский для
  ru/be/kk/uk/uz, английский для остальных (`src/i18n.js`).
- **Сохранение прогресса** — через `player.setData`. Записи буферизуются: не
  чаще раза в 3 секунды плюс в ключевые моменты (конец уровня, покупка).
  Лимит Яндекса — 100 запросов за 5 минут, посохранять каждую монетку нельзя.
- **Гостевой режим** — неавторизованный игрок сохраняется в localStorage.
- **Звук глохнет** при потере фокуса вкладки, игра встаёт на паузу.
- **Нет контекстного меню и прокрутки**, длинное нажатие ничего не выделяет.
- **Поворот экрана и любой размер окна** — режим Phaser.Scale.FIT.
- **Реклама** — только межстраничная, между уровнями и не чаще раза в
  3 минуты (`ADS` в `src/config.js`, можно отключить одним флагом).
  Реклама за награду в SDK подключена, но в игре пока не используется.

## Что стоит сделать перед публикацией

1. **Сверить ссылку на SDK.** В коде `https://yandex.ru/games/sdk/v2` — так в
   актуальной документации Яндекса; в конспекте `docs/yandex-games.md`
   записан старый вид `sdk.js`. Перед отправкой проверить по оригиналу.
2. **Проверить в Консоли разработчика** через debug-панель: индикатор `IT`
   (SDK подключён) и `文` (автоопределение языка).
3. **Больше содержания.** Яндекс требует, чтобы основное прохождение занимало
   **больше 10 минут** — три уровня по 1–2 минуты этого не дают. Нужно
   довести до 6–8 уровней или добавить причину переигрывать.
4. **Проверить на телефоне** — экранные кнопки и игру одной рукой.
5. Иконка, обложка, скриншоты реального геймплея, описание на двух языках.

## Файлы

```
src/
  main.js          запуск игры, настройка Phaser
  config.js        все числа: физика, звёзды, реклама
  levels.js        карты уровней в символах
  art.js           генерация всех текстур кодом
  capybara.js      внешний вид и анимация героя
  background.js    небо, холмы, облака (параллакс)
  audio.js         звук синтезируется, файлов нет
  save.js          прогресс с буферизацией записи
  shop.js          товары магазина
  i18n.js          русский и английский
  ui.js            кнопки, панельки, звёзды
  platform/        адаптеры площадок (local, yandex)
  scenes/          Boot, Menu, LevelSelect, Shop, Game, Result
```
